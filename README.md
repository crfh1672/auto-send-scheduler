# Auto Send Scheduler
 
**🌐 [לדף הפרויקט](https://crfh1672.github.io/auto-send-scheduler/)**
 
תוסף כרום (Manifest V3) שמתזמן **הקלדה ושליחה אוטומטית של הודעה** בטאב פתוח, בעוד זמן מסוים או בשעה מסוימת. נבנה לשימוש בעיקר עם Claude (claude.ai), אבל לא קשור לאתר מסוים.
 
> **סטטוס:** הקוד נכתב ועבר בדיקת סינטקס, אך לא נבדק מקצה לקצה על claude.ai. ראו "מגבלות ידועות" ו"התאמה ל-claude.ai".
 
## למה זה שימושי
 
אתרי צ'אט, Claude כולל, שולחים רק כשלוחצים בעצמכם. התוסף מאפשר לשלוח כשאתם לא מול המחשב:
 
- **משימות ארוכות בלילה:** מכינים הכול מראש ושולחים בבוקר.
- **מכסה שמתחדשת:** מתזמנים הודעה לרגע שבו מכסת השימוש חוזרת.
- **שעה קבועה:** הודעה יומית או הנחיה קבועה שיוצאת בזמן שהגדרתם.
- **פרטיות:** הכול רץ בדפדפן. ההודעה נשמרת מקומית ולא נשלחת לשום שרת.
 
## איך מפעילים
 
1. פותחים את הטאב שבו רוצים לשלוח, למשל שיחה ב-Claude.
2. לוחצים על אייקון התוסף וכותבים את ההודעה.
3. בוחרים **מתי לשלוח**:
   - **בעוד זמן מסוים:** מספר דקות (מינימום חצי דקה, מגבלה של `chrome.alarms`).
   - **בשעה מסוימת:** שעה ביום. אם השעה כבר עברה היום, השליחה תהיה מחר.
4. לוחצים "תזמן הפעלה". אפשר לעבור לטאב אחר או לצמצם את החלון.
5. בזמן היעד התוסף מכניס את הטקסט לתיבת הכתיבה ושולח בלחיצת **Ctrl+Enter** אמיתית.
 
## למה השליחה אמינה
 
- **תזמון מחוץ לדף:** נשען על התראות של כרום, ולא על טיימר שמואט כשהטאב ברקע.
- **לחיצת מקלדת אמיתית:** אתרים שמתעלמים מלחיצות מדומות יקבלו אותה.
- **טאב שנסגר:** נפתח מחדש ברקע לפי הכתובת השמורה.
- **משימה באיחור:** אם המחשב ישן בזמן היעד, ההודעה תישלח כשהדפדפן יחזור לפעול.
 
## התקנה
 
1. הורידו או שכפלו את הריפו.
2. **ליצירת האייקונים** (נדרש פעם אחת, אם התיקייה `icons/` חסרה):
```bash
   pip install pillow
   python scripts/generate_icons.py
```
3. ב-`chrome://extensions` הפעילו "מצב מפתח" ולחצו "טען תוסף לא ארוז", ובחרו את תיקיית הפרויקט.
4. אשרו את ההרשאות (גישה לאתרים ודיבוג).
5. מומלץ: בהגדרות כרום ← ביצועים ← Memory Saver, הוסיפו את האתר ל-"Always keep these sites active".
 
## מבנה הפרויקט
 
| קובץ | תפקיד |
|---|---|
| `manifest.json` | הגדרות התוסף והרשאות |
| `popup.html` | ממשק החלון הקופץ (עברית, RTL, תומך מצב כהה) |
| `popup.js` | קורא את הטופס, מחשב את זמן היעד, שומר את המשימה ב-`chrome.storage.local` ויוצר התראה |
| `background.js` | Service worker: מקשיב להתראה, מכין את הטאב, מכניס טקסט ושולח |
| `icons/` | אייקוני התוסף (16/32/48/128) |
| `docs/index.html` | דף נחיתה (GitHub Pages) |
| `scripts/generate_icons.py` | יוצר את האייקונים |
| `CLAUDE.md` | הקשר טכני לסוכן/Claude שממשיך לפתח את הפרויקט |
 
## איך זה עובד
 
**תזמון.** ב-`popup.js` נשמרת משימה תחת המפתח `sendTask_<tabId>` עם `message`, `tabId`, `url` ו-`due` (זמן יעד במילישניות). נוצרת התראה באותו שם: `delayInMinutes` או `when`.
 
**ביצוע (`background.js`).** כשההתראה מופעלת:
1. המשימה "נתפסת" (נמחקת מה-storage) כדי למנוע שליחה כפולה, ומוחזרת אם הביצוע נכשל.
2. אם הטאב נסגר, נפתח מחדש ברקע לפי ה-`url` השמור. אם הוא הורדם על ידי כרום, הוא נטען מחדש.
3. מחכים לסיום הטעינה.
4. `insertText` מוזרק לדף: מוצא `textarea` או `[contenteditable="true"]`, כותב את הטקסט ומשגר אירועי `input` ו-`change`.
5. `trustedCtrlEnter` מחבר את `chrome.debugger` לטאב ושולח אירועי מקלדת אמיתיים (`Input.dispatchKeyEvent`, `isTrusted: true`). כך השליחה לא תלויה בטיימרים של דף מוסתר, ואתרים שמתעלמים מאירועים סינתטיים יקבלו אותה. `Emulation.setFocusEmulationEnabled` מאפשר לזה לעבוד גם בחלון ממוזער.
 
**התאוששות.** `onStartup` ו-`onInstalled` מריצים משימות שהזמן שלהן כבר עבר (למשל אחרי שהמחשב התעורר).
 
## הרשאות
 
| הרשאה | למה |
|---|---|
| `alarms` | תזמון ארוך שלא תלוי ב-service worker חי |
| `storage` | שמירת המשימות |
| `scripting` + `host_permissions: <all_urls>` | הזרקת הטקסט גם אחרי ניווט או רענון |
| `tabs` | בדיקת מצב הטאב, פתיחה מחדש וטעינה מחדש |
| `debugger` | לחיצת מקלדת אמיתית (יציג בטאב פס "התוסף מבצע דיבוג" לרגע) |
| `background` | שומר את כרום רץ ברקע גם כשכל החלונות סגורים |
| `activeTab` | זיהוי הטאב הפעיל בחלון הקופץ |
 
`<all_urls>` רחב. אפשר לצמצם לדומיין אחד (למשל `https://claude.ai/*`) ב-`host_permissions`.
 
## מגבלות ידועות
 
- **דפדפן סגור לגמרי, מחשב כבוי או בשינה:** התוסף לא יכול לרוץ. משימה באיחור תבוצע כשהדפדפן יחזור לפעול. לתזמון מחוץ לדפדפן צריך מתזמן של מערכת ההפעלה.
- **טאב שנסגר:** נפתח מחדש לפי הכתובת השמורה. אם השיחה לא נקבעת לפי הכתובת, ההודעה תישלח בדף הכללי.
- **לא נבדק על claude.ai.** ראו הסעיף הבא.
- משימה אחת לכל טאב: תזמון חדש באותו טאב דורס את הקודם.
- החלון הקופץ ב-popup.html צר, ואין כרגע רשימה של משימות ממתינות או ביטול.
 
## התאמה ל-claude.ai
 
תיבת הכתיבה ב-claude.ai היא עורך עשיר (`contenteditable`), ולא `textarea`. לכן ייתכן שיידרשו התאמות ב-`background.js`:
 
- **הכנסת הטקסט:** `field.textContent = ...` עלול לא להירשם בעורך. אלטרנטיבה: `document.execCommand('insertText', false, text)` אחרי `field.focus()` ובחירת התוכן הקיים.
- **שליחה:** אם Ctrl+Enter לא שולח, שנו את `modifiers: 2` ל-`0` ב-`trustedCtrlEnter` (Enter רגיל), או הוסיפו לחיצה על כפתור השליחה עם `field.closest('form')?.querySelector('button[aria-label*="Send" i]')`.
- **בחירת השדה:** אם הדף מכיל כמה שדות, חדדו את הסלקטור ב-`insertText`.
 
## אבטחה ופרטיות
 
התוסף לא שולח נתונים לשום שרת. ההודעה והכתובת נשמרות רק ב-`chrome.storage.local` עד לביצוע. הרשאת `debugger` חזקה, ולכן מומלץ לא להתקין תוספים לא מוכרים לצידו.
